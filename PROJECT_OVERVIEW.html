Human Activity Recognition — Assignment 3

Project file overview · what each file is and how it contributes to the result

Final result: 0.8267 public macro-F1 (Baseline-3 to beat was 0.7088).
A 6-model ensemble: LightGBM + XGBoost + CatBoost + MLP on 334 hand-crafted features, plus a CNN-LSTM and a ROCKET model on the raw 6×300 signal, combined with a hill-climbing weighted blend and a per-class offset correction.

Pipeline order

data_loader→ eda→ naive_baseline→ feature_engineering→ train_lgbm / xgb / catboost / mlp→ train_cnn→ train_rocket→ ensemble→ make_report_assets / docx

One command runs all of it: .\run_all.ps1. Or open HAR_pipeline_inline.ipynb and run top-to-bottom.

How to read the "review" column

READ grader-facing prose — read it for accuracy SKIM code with dev-note comments — glance over the claims SAFE pure mechanical code — no claims to verify

2. Feature engineering

FileWhat it isContribution to the resultReview

SKIM: the header comment summarises which feature ideas worked and which (gravity, wavelet) were tried and dropped — all verified against the leaderboard.

train_rocket.pyROCKET: thousands of random convolution kernels on the raw signal.Diverse raw-signal model (~0.667); broke the tree-saturation plateau.SKIM

SKIM note for train_cnn.py: it has optional --focal-loss / --boost-rare flags that are off by default — the final model uses plain class-balanced cross-entropy (this is stated in the code comment).
